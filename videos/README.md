# Scene videos

Drop your filmed scenes in this folder with these exact names and they show up automatically on the matching station's **Scene** tab:

| File | Station |
|---|---|
| `crash.mp4` | 1961 · The Night Train |
| `birth.mp4` | 1968 · A Name in a Hurry |
| `kindergarten.mp4` | 1973 · Two Names at School |
| `gift.mp4` | 1982 · The Gift |
| `nikhil.mp4` | 1986 · "I'm Nikhil" |
| `truth.mp4` | 1987 · The Truth in the Car |
| `phonecall.mp4` | 1990s · The Phone Call |
| `finale.mp4` | 2000 · The Man Who Gave You His Name |

Export as **MP4 (H.264)**, 1080p or 720p. Keep each one under ~100 MB so GitHub accepts it.
To use a different filename, change the `video:` line for that station in `index.html`.
