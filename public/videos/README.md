# Scene videos

These files are in this folder with these exact names and show up automatically full screen when the train reaches the matching station:

| File | Station |
|---|---|
| `nikhil.mp4` | 1986 · "I'm Nikhil" |
| `ratliffs.mp4` | 1990s · The Ratliffs |
| `phonecall.mp4` | 1990s · The Phone Call |
| `apart.mp4` | ~2000 · Coming Apart |


Export as **MP4**, 720p is fine. Keep each one under 50 MB (GitHub refuses files over 100 MB, and big files slow the site down). HandBrake's "Fast 720p30" preset usually gets a 1–2 minute scene well under that.
